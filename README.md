# QA Bug Reports

Bug reports I wrote while testing [saucedemo.com](https://www.saucedemo.com), a practice e-commerce site with intentional bugs, using the `problem_user` account.

## Report format
Each report includes a title, environment, steps to reproduce, expected result, actual result, severity, priority, and a screenshot.
